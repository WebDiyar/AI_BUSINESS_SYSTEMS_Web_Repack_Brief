# AI BUSINESS SYSTEMS — сайт

Статический сайт (HTML + CSS, без JavaScript и без сборки). Тестовая переупаковка главной страницы под бренд AI BUSINESS SYSTEMS.

## Структура

| Путь | Что это |
|------|---------|
| `site/` | **Сайт.** Правится `site/index.html`. Именно эта папка публикуется |
| `source/` | Исходный снимок сайта заказчика. Не менять |
| `assets/` | Референсы бренда (логотип, панорама) |
| `screenshots/` | Скриншоты «до» и «после» |
| `docs/` | Документация по этапам |
| `start.sh` | Локальный запуск |
| `vercel.json`, `.vercelignore` | Настройки публикации на Vercel |

## Запуск локально

```bash
./start.sh        # или: npm start
```

Скрипт берёт свободный порт (с 8000), открывает браузер, слушает только `127.0.0.1`. Остановка: `Ctrl+C`.
Если папки `site/` нет, скрипт создаёт её из `source/` без `CNAME`.
Нужен только Python 3. Альтернатива: расширение Live Server в VS Code (настроено на `site/`).

## Скрипты

| Команда | Что делает |
|---------|-----------|
| `npm start` | запускает сайт локально |
| `npm run check` | ищет остатки «STRATIVON» в `site/index.html` |
| `npm run preview` | тестовый деплой на Vercel (временная ссылка) |
| `npm run deploy` | деплой на Vercel в production **своего** проекта |

`preview` и `deploy` запускают Vercel CLI: при первом запуске он попросит войти (`vercel login`) и создать проект. Ничего публиковать на домен заказчика не нужно.

## Публикация на Vercel

Настройки лежат в `vercel.json`: сборки нет, отдаётся папка `site/`.

**Через GitHub (рекомендуется):**
1. Залить проект в **приватный** репозиторий. В нём лежат материалы заказчика (PDF и референсы).
2. Vercel → Add New → Project → выбрать репозиторий.
3. Framework Preset: **Other**. Root Directory: `./`. Остальное не менять — подхватится из `vercel.json`.
4. Deploy. Каждый `git push` в `main` обновляет сайт.

**Через консоль:**
```bash
npx vercel          # тестовая ссылка
npx vercel --prod   # постоянная ссылка проекта
```

**Только папка `site/`:** можно задеплоить и её одну (`cd site && npx vercel`), конфиг не нужен.

Не привязывать к тестовому сайту домен `angletheory.studio` и не копировать `CNAME`.
