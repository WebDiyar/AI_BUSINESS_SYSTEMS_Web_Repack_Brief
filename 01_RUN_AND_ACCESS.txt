ЗАПУСК И ДОСТУП

Исходный сайт: https://angletheory.studio/
Репозиторий: https://github.com/angle-theory-studio/angletheory-site
Публикация заказчика: GitHub Pages. Стек текущей версии: HTML и CSS.

1. Полностью распакуйте ZIP, затем откройте папку source/ в VS Code
   или другом редакторе. Редактируемый файл: source/index.html.
2. Для просмотра используйте локальный статический HTTP-сервер.
   При установленном Python 3 откройте терминал внутри source/ и выполните:
   python -m http.server 8000
   На системах с командой python3: python3 -m http.server 8000
3. Откройте http://localhost:8000/ в браузере.
   Остановка сервера: Ctrl+C.
   Если Python отсутствует, можно использовать привычный локальный
   статический сервер; в VS Code также подходит Live Server.
4. До изменений сохраните исходную копию. Скопируйте нужные PNG из assets/
   в рабочую копию сайта и используйте относительные пути к ним.
5. Работайте в своей копии / fork. Пароли, токены, доступ к домену и
   приглашение в основной репозиторий для этого задания не нужны.
6. Для тестовой публикации разместите свою копию отдельно.
   В своей тестовой копии удалите или отключите CNAME с рабочим доменом;
   не привязывайте angletheory.studio к тестовому сайту.
   В исходном репозитории заказчика CNAME и main не изменять.
7. Верните ссылку на тестовую версию и ZIP исходников либо ссылку
   на свой репозиторий/PR. Изменения проверяет заказчик.
   Публикация на рабочем домене в задание не входит.

Если при запуске что-либо не работает, пришлите текст ошибки,
использованную команду и сведения о среде.
