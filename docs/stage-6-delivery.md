# Этап 6. Публикация и сдача

**Статус:** ✅ публикация и отчёт готовы 15.10.2026; ждёт отправки заказчику ([delivery-report.md](../docs2/delivery-report.md)). План: 1,5 ч. Срок: 17.10.2026, 20:00 (UTC+5), если не пересогласован.

## Зачем

Заказчик проверяет **отдельную тестовую версию**. Рабочий сайт и их репозиторий не трогаем.

## Шаги

1. **Тестовая публикация** (на выбор):
   - свой репозиторий на GitHub, залить содержимое `site/`, включить GitHub Pages;
   - или **Vercel** (настроен в `vercel.json`, инструкция в корневом `README.md`): импорт репозитория, Framework Preset «Other», либо `npm run preview` / `npm run deploy`;
   - или Netlify Drop (перетащить папку `site/`).

   Репозиторий для Vercel делать **приватным**: в нём материалы заказчика.

   Без `CNAME`, домен angletheory.studio не привязывать.
2. Проверить опубликованную версию так же, как локальную (этап 5).
3. Снять финальные скриншоты в `screenshots/final/`: компьютер и телефон.
4. Собрать ZIP исходников (содержимое `site/`) или дать ссылку на репозиторий.
5. Написать отчёт HR.

## Что должно быть в отчёте

- ссылка на тестовую версию
- ZIP или репозиторий
- инструкция запуска: `./start.sh` или `python3 -m http.server`; зависимостей нет (кроме Google Fonts, если подключены)
- скриншоты компьютера и телефона
- краткий список изменений
- проведённые проверки
- известные ограничения:
  - логотип и фон сделаны по скриншотам, оригиналов не было;
  - og:image заработает только на рабочем домене
- фактически затраченные часы (из [progress-log.md](progress-log.md))
