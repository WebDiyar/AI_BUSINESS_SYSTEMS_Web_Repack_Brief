# Правила и границы

## Нельзя

- Менять `source/`, рабочий домен, репозиторий заказчика и их `CNAME`.
- Вставлять страницу одной картинкой, вставлять интерфейс телефона и галереи со скриншота.
- Переносить услуги с картинки (MARKETING, DEVELOPMENT и т. п.).
- Придумывать кейсы, отзывы, клиентов и цифры.
- Менять тексты по смыслу, контакты, назначение продукта и обещания.
- Менять постоянный адрес `og:url`.
- Добавлять платные зависимости, менять платформу и переписывать проект с нуля без согласования.
- Перерисовывать логотип, менять его надписи и пропорции.
- Отправлять реальные тестовые заявки без согласования.

## Нужно

- Работать только в `site/`, коммитить после каждого этапа.
- Текст оставлять живым (не картинкой), сохранять читаемость при свечении и фонах.
- Сначала согласовать первый экран, потом остальное.
- Не позже чем за день предупреждать HR, если срок сдвигается: причина, готовность, новая дата.
- Спорные упоминания старого названия согласовывать.

## Условия отбора

Неоплачиваемое задание. Оцениваются качество и скорость вместе.
